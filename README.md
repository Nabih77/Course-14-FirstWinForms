# Course 14-FirstWinForms

C# Windows Forms - Learning Controls 🚀

Welcome to my repository! This is my first C# desktop application project created in Visual Studio 2022.

📌 About The Project

The purpose of this project is to practice and understand how standard Windows Forms controls work in C#, how to handle events, and explore basic 2D graphics.

🛠️ Controls Practiced in this Project

Here are some of the main forms and controls implemented:

TextBox & Labels: Handling text input and displaying output.
CheckBoxes & RadioButtons: Managing selections and boolean states.
PictureBox: Loading, displaying, and managing images.
MessageBox: Displaying alert dialogues and confirmations.
Drawing (frmDraw): Custom 2D graphics using System.Drawing, Graphics.DrawLine, and Graphics.DrawRectangle.

💻 Tech Stack
Language: C#
Framework: .NET (Windows Forms)
IDE: Visual Studio 2022
Version Control: Git & GitHub
